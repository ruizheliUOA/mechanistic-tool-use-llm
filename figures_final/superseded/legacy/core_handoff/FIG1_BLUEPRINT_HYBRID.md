# Blueprint 3 — MECHANISM + CLAIM-LAYER HYBRID  (spatial logic only)

Mechanism compressed to an inset; the claim structure carries the composition.

```
  (a) MECHANISM (inset, ~35% of area)        (b) MOVEMENT IS NOT CORRECTION
  [req] -> [B1..B21*..B26*..B35] -> [a']         c=(g->s) -.
              ^          |                                  |-> SOURCE_RETAINED  still wrong
              |          v                                  |-> GOLD_ARRIVAL     correct
              +---- [router] (offline, cached)              '-> OTHER_WRONG      still wrong
              two passes; L_inj < L_obs
                                                 aggregate collapses {SR, OW}

  (c) CLAIM LADDER
                                        ,--- LICENSABLE ---,   (bracket ABOVE,
                                        |   evidential      |    not a rung)
      [ READ ] -> [ CONTROL ] -> [ REPAIR ]
      Readable     Steerable      Correctable
      ================= ADJUDICABLE (ground the ladder stands on) =============
      Specificity | Destination | Preservation | Yield | Evidence  --^
```

Strength: the property/licence distinction is carried by geometry rather than by
labels; Licensable physically cannot be misread as a fourth rung.
Weakness: mechanism is demoted, so Methods must carry more of the topology.
Recommended if Figure 1 must be the conceptual contribution.
