# Formal breadth, and principle versus validation

## Evidence hierarchy, by generation

| level | settings | generation |
|---|---|---|
| **formal licence outcomes** | Qwen3-8B, Qwen3-4B, Gemma-2-9B | prospective, sealed, one-shot |
| **prospective early stop** | Qwen3.5-9B | prospective; SEALED never opened |

```
FORMAL_BREADTH_FOR_CURRENT_NARROW_THESIS:  SUFFICIENT
FORMAL_BREADTH_FOR_UNIVERSAL_GENERALIZATION: INSUFFICIENT
```

These are different questions and the paper must never collapse them.

## Conceptual generality of the core

`Adjudicable → [Readable → Steerable → Correctable] → Licensable`, with `c = (g→s)` and
`SOURCE_RETAINED / GOLD_ARRIVAL / OTHER_WRONG`, is defined over a dataset-native action set
`A_D`. Every estimand is a count, rank or probability. No benchmark's label names appear in the
general form, and the destination classifier in the frozen code references no W2C label. The one
structural requirement is `|A_D| ≥ 3`, which is a stated scope condition, not a hidden assumption.

**ACTION-SPACE GENERAL** in definition; demonstrated on two ontologies in practice.

```
CONCEPTUAL_GENERALITY: STRONG
EMPIRICAL_GENERALITY:  PARTIAL
```

## The formulation this licenses

> SAKIKO provides a general adjudication principle demonstrated rigorously in a limited set of
> formal settings.

It must never become *"a universally validated general correction framework."*

## Paper identity

**PAPER A** (universal method: "SAKIKO identifies correctable channels across models and
datasets") — **not supported**, and the paper does not claim it.

**PAPER B** (evidential/methodological: "SAKIKO operationalises a staged standard for when
intervention-induced movement warrants a correction claim, and demonstrates heterogeneous
stopping outcomes") — **strongly supported**.

The work should not be penalised against Paper A's breadth requirement when it is written as
Paper B. That is the correct identity and the drafts already carry it.
