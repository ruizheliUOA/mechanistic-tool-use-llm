# Manuscript figures

Files are named for what they show. Each is generated by the R script of the same
name in `figures_final/R/`; none is edited by hand.

| file | shows | where it belongs | script |
|---|---|---|---|
| *(author's own diagram)* | the SAKIKO framework: model-side setup, directional error channels, pre-execution decision space | Introduction, Figure 1 of the current build | — supplied by the author |
| `correction_is_not_repair.pdf` | (a) one intervention with every outcome resolved · (b) target-hit with 95% intervals against the 0.50 criterion | the paragraph stating the finding, Introduction / §3 | `R/correction_is_not_repair.R` |
| `direction_specificity.pdf` | (a) the Phi-3.5 control battery · (b) all 59 matched random directions per sealed setting | §4.3 | `R/direction_specificity.R` |
| `destination_and_preservation.pdf` | (a) activation against the score-space comparator · (b) collateral on both denominators | §5.1–5.2 | `R/destination_and_preservation.R` |
| `evidence_ladder.pdf` | the property and verdict map for all seven settings | §5.4 | `R/evidence_ladder.R` |
| `historical_record.pdf` | (a) collateral of every Phi-3.5 seed · (b) the Qwen2.5-7B locked battery | Appendix D | `R/historical_record.R` |

Every figure has at most two panels, and no panel appears in more than one figure.
The target-hit intervals appear only in `correction_is_not_repair` panel (b); §5.3
refers back to them rather than repeating the plot.

`fig2_framework.pdf` is a generated framework diagram kept only as a fallback. The
author's own diagram covers the same ground and is already Figure 1 of the build, so
the manuscript should not include both.

## How a number reaches a figure

```
final_evidence/FINAL_PAPER_EVIDENCE.csv   frozen verdict artifacts
                    \                        /
             figures_final/_panels.py : load_all()      <- reads and asserts
                             |
             figures_final/export_figure_data.py        <- reshapes, no arithmetic
                             |
                  figures_final/data/*.csv              <- tidy, one table per panel
                             |
                  figures_final/R/*.R                   <- plots only
                             |
                        figures/*.pdf
```

## Regenerating

```
cd SAKIKO-paper
python figures_final/export_figure_data.py          # only if the evidence changed
for f in figures_final/R/*.R; do [ "$(basename $f)" = theme_sakiko.R ] || Rscript "$f"; done
```

Requires R with ggplot2, patchwork and ggrepel. PDFs go through `cairo_pdf` and embed
TrueType Times New Roman; none contains a Type 3 font.

## Not in the manuscript

`figures_final/superseded/` holds the earlier matplotlib generation and the mechanism
figure, to be re-cut in R when that section is drafted. `main/`, `v2/`, `source/` and
`core_handoff/` hold pre-2026-09 work; two of those are earlier "SAKIKO core"
schematics whose numbers predate the frozen evidence and must not be reused.
